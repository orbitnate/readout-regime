# readout-regime

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Python 3.9+](https://img.shields.io/badge/python-3.9%2B-blue.svg)](https://www.python.org/)
[![Verify T1](https://img.shields.io/badge/T1%20identity-verified%20%E2%89%88%201e--15-brightgreen.svg)](tests/test_t1_closed_form.py)

Companion code and result artifacts for the paper **“The Readout Regime: A Normal
Form for Final-Residual Control of Frozen Transformers — and Its Capacity Limits.”**
The paper is included in [`paper/readout_regime.md`](paper/readout_regime.md).

> **In one sentence.** A vector added to a frozen transformer’s **final residual
> stream** (the readout space — installing a scaled row of `lm_head` is the
> exactly-characterizable case) acts on the logits, for *every* input, as
> `z ↦ s(x)·z + c(x)`: a ranking-preserving scalar temperature `s(x) > 0` plus a
> re-ranking bias `c(x)` confined to a **fixed, low-dimensional cone chosen before
> any input is seen**. So a readout install can re-weight and re-rank the options
> the model already has, but **cannot synthesize a new answer direction or compute
> a hidden routing variable** the addressing query does not already expose.

This repo lets you check that claim two ways: a **model-free proof** that the
transform is an exact algebraic identity (runs in a second, no GPU), and the
**experiment scripts + result artifacts** behind every number in the paper.

---

## Quickstart

```bash
git clone https://github.com/orbitnate/readout-regime.git
cd readout-regime
python -m pip install -r requirements.txt        # for the experiments; the test below needs only numpy

# 1) Model-free: prove the readout transform is an exact identity (no model, no GPU)
python tests/test_t1_closed_form.py
```

Expected output:

```
T1 / T2 model-free verification (float64, synthetic unembedding)
----------------------------------------------------------------
  Lemma 1 (no-norm)   max|direct - closed| = 1.12e-15   (< 1e-10)
  Lemma 3 (RMSNorm)   max|direct - closed| = 1.05e-15   (< 1e-9)
  temperature s = r/r' = 0.966405  (> 0, ranking-preserving)
  T2' cone rank: re-ranking residual rank = 4 <= m = 4 slots
----------------------------------------------------------------
PASS: ...
```

That test reproduces, model-free, the same identity the paper verifies on real
7B checkpoints (where the residual is `~5e-6` in fp32). To reproduce it *on a
model*, run `experiments/01_closed_form`.

| [**Tier-B walls (C1/C3)**](experiments/07_tier_b_walls) | §7, B.6–B.8 | what the readout regime *can’t* do: bounded readout-wall; single-pass multi-hop **0.183 vs 0.40**; composition **272/272 oracle** vs hidden route **189/272 (fails its gate)** | 📦 **Archived** (GPU/Spark) |

**Tier legend.** ✅ **Runnable** = clone-and-run on a single ≤7B checkpoint (forward-only;
no training); the committed JSON is regenerated by the command in the folder README.

**authentic source script is included as a reference**, but reproducing it needs
either multi-GPU (14B/72B) or the larger experimental harness it was run under (the
`pitwm` package, not vendored here). Nothing is re-derived or re-typed: archived
artifacts are the original run outputs.

## Models and data

All results use **public, instruction-tuned checkpoints** — Qwen2.5
(1.5B/7B/14B/72B), Llama-3.1-8B, Mistral-7B-v0.3, and Pythia-1.4B/12B — loaded from
the Hugging Face Hub, with **forward-only** instrumentation (forward hooks). **No
weights are trained or modified.** Datasets named where used: MMLU, GSM8K, and
HumanEval (no-harm sweep) and MQuAKE-CF (multi-hop). The synthetic chains used by
the runnable probes are vendored under each folder’s `data/`.

## Scope and honesty

This is a **theory + diagnostics** repository. A few load-bearing caveats, carried
verbatim from the paper (see §4–§7) so they are not lost in the code:

- **The two theorems are algebraic.** T1, T2, and T2′ are proved in the paper’s
  Appendix A; no experiment is required to establish them. The closed-form check
  (`tests/` and `01_closed_form`) is a *sanity test on the algebra*, not evidence.
- **Tier A vs Tier B.** Only final-residual (`final-norm pre-hook`) installs test
  the exact object T2 governs. The recall/composition results inject at a *late
  layer* (L27/L30); there the same boundary pattern is **empirically visible**
  (bias-only tasks succeed, computation/chaining tasks wall), but T2 does not
  formally govern late-layer installs.
- **Composition is an upper bound, not recovery.** The `272/272` composition is the
  **oracle / exact-delta** upper bound; the **learned hidden route reaches only
  189/272 and fails its pre-registered gate** — it is codebook regression error,
  **not** module recovery.
- **Multi-hop is a locus-confounded near-miss.** The `0.183` figure installs at the
  subject positions and re-encodes the bridge, so it is not a pure final-residual
  wall.
- **The basis privilege is at the argmax-flip level.** On instruction-tuned models a
  norm-matched random install still lifts the target logit (an off-axis attractor,
  Figure 2); only the genuine `lm_head` row owns the *flip*.
